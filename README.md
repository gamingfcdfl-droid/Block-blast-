🎮 Block Blast

Welcome to Block Blast!

A fun block puzzle game where you place blocks, clear rows and columns, and earn points.

Features

- Drag and drop blocks
- Earn coins and rewards
- Unlock different themes
- Daily challenges
- Local leaderboard
- Save your progress on your device
- Installable as an app (supported browsers)

How to Play

1. Drag a block onto the board.
2. Complete a row or column to clear it.
3. Earn points and coins.
4. Keep playing and beat your best score!

Enjoy playing Block Blast! 🚀
